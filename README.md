# Nyelvin

Nyelvin (from Hungarian `nyelv`, meaning language + Finnish instructive suffix `-in`) is a conlaning application. Although it's not very complete yet, I've planned some enticing features:
- Integrated proto-langing support (proto-lang reconstructions, free Markdown notes, integrated sound change engine)
- Complex inflection: PolyGlot-style regexes, but for simpler cases basic suffixing along with defining a word's root based on its morphology. The aim overall is to reduce the repetition with other conlanging toolkits.
- Project sharing online
- Import/export to JSON
- etc

Current state:
- A very basic lexicon
- Saving/opening
- Tags/POS (under construction)

The application is built with [Wails v3](https://v3.wails.io/) and React + MUI. I'm using MUI for its rich ecosystem/accessibility support (and my experience with it) but I don't want this to look like a Google product, so custom styles and 3rd-party icons are used.
